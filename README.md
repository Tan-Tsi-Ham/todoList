# 背景
感觉游戏里的任务界面好像挺清晰的，每天两眼一睁就是打卡、活动、剧情过一遍，非常高效又孜孜不倦。于是想着，现实中的日程规划能否也用类似的思路，于是做了这个页面。
# 介绍
分成三个界面：今日任务、近期任务、过往任务。
## 近期任务
整理一下近期的一系列任务，做一下归类分成**任务组**，任务组之下再新建**具体任务**。任务组就像游戏里那些会更新的任务一样，例如任务组“todoList”，下设任务“写个readme”“取个好听的名字”“设计一个好看的logo”。

每个任务必须隶属于某一个任务组，其他基础设置如“描述”“截止时间”“重复方式”，还有2个特殊设置：
### 在主界面显示
这个的意思是，任务会显示在“今日任务”的界面里，也就是默认界面/主界面。有的任务虽然是准备要做的，但可能不是今天或者不是最近几天，不记录的话容易忘，所以可以先记录，然后不让它在“今日任务”里显示，只会在“近期任务”里显示。
### 上一个任务完成后才开始
这个的意思是，只有上一个任务完成之后才能完成。灵感来自于游戏中的剧情，剧情是有严格时间顺序的，在遇到反派之前是没办法提前将反派打败的。现实中也有类似的任务，例如画一幅画，可能就规划“打草稿”→“画线稿”→“描边”→“涂色”→“晒画”，就可以勾选此项。

❗不过此项好像还有些瑕疵，时序靠后的任务居然是可以直接和时序考前的任务一起显示在“今日任务”里的，这放在游戏剧情的视角看是大逆不道的。笔者后面有时间再看看怎么改。
## 今日任务
这个界面就放一些今天或者最近几天想做的事情。平时活着主要看这个界面就行，等这个界面空了或即将空了的时候，再去“近期任务”界面看看还有啥可以添加进来的。再没有就自己创建一些吧。

任务完成后直接打勾即可，打完勾后任务不会消失。因为看着一堆做完的任务会非常有成就感；而且有时候会出现误打勾的情况，不消失才能把勾取消掉。

要隐藏做完的任务，右侧有“移入历史”的选项，点击之后任务就出现在“过往任务”里，“今日任务”和“近期任务”里不再显示。

## 过往任务

如果手误把任务放入“过往任务”中，点击“移出历史”。

在“近期任务”中，如果确认某任务组不会再更新了，就例如游戏里某些活动过期了不会再有了，可以将整个组“移入历史”，这样就不会“近期任务”里显示了。比较念旧的人可以在“过往任务”里找到这些曾经做过的任务。
